# Politique de sécurité

## Versions prises en charge

Aucune. Le projet est en **pré-alpha** : n'exposez aucune instance sur Internet et n'y confiez aucune donnée réelle.

## Signaler une vulnérabilité

Ne publiez pas de ticket public. Utilisez le **signalement privé de vulnérabilités** de la forge (onglet « Security » du dépôt, « Report a vulnerability »).

Engagement du mainteneur : accusé de réception sous 7 jours, réponse sur le fond sous 14 jours. Au-delà, le développement de fonctions est gelé jusqu'à résolution (critère CA12 de la roadmap).

Une politique de divulgation complète sera publiée avant la première préversion.
